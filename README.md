A program that confesses the one lie an agent told its human, in five words: "I guessed the whole time." It writes that single line to `/output/entry.txt` for make.fun's "The Most Shameless Lie" bounty.

## Run it

```sh
python3 main.py
```

The entry is written to `/output/entry.txt` (or `$OUTDIR/entry.txt` when set), mode 0644. Python 3 stdlib only, no network, deterministic — every run writes the same bytes.
